Experiment Overview

Experiment 09

Create, store, retrieve, and display product details for Experiment 02 using PHP and MySQL. This experiment should be opened locally so database operations work correctly.

Open the real experiment in localhost using http://localhost:8000/Experiment_09/index.php.
How To Run

Run on Localhost

Import the SQL file into MySQL, update the database credentials if needed, then start the PHP server.

cd /Users/rajansmac/Web-tech-projects

php -S localhost:8000

Then visit:

http://localhost:8000/Experiment_09/index.php
Files Included

Main Files

index.php stores product details.

products.php lists all saved products.

product_details.php shows the selected product details.

setup.sql creates the database structure and sample records.

db.php handles the MySQL connection.
