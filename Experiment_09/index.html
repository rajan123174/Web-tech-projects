Experiment 09

Create, store, retrieve and display the product details for Experiment 2 using PHP and MySQL.

Files Included

index.php for storing product details

products.php for retrieving and displaying all products

product_details.php for displaying one selected product

setup.sql for creating the MySQL database and sample records

db.php for database connection

How to Run

1. Create the database by importing setup.sql into MySQL.

2. Update database username and password in db.php if needed.

3. Run a local PHP server from the project root.

cd /Users/rajansmac/Web-tech-projects

php -S localhost:8000

4. Open http://localhost:8000/Experiment_09/index.php

Why this page is HTML

GitHub Pages does not execute PHP or MySQL. This HTML page opens correctly online, while the actual PHP and MySQL functionality runs locally or on a PHP server.
