Experiment 08

This experiment demonstrates form handling and form validation using PHP.

Why it was downloading

GitHub Pages supports only static files such as .html, .css, and .js. It does not execute .php files, so clicking a PHP file may download it instead of opening it as a web page.

Files in this experiment

The PHP implementation is available in Experiment_08/index.php.

This page is a GitHub Pages friendly entry page so the experiment opens properly online.

How to run the PHP form

Run the project on a local PHP server and open the PHP file in your browser.

Example:

cd /Users/rajansmac/Web-tech-projects

php -S localhost:8000

Then open http://localhost:8000/Experiment_08/index.php

What the PHP page contains

It includes two validated forms:

1. Personal contact form based on Experiment 1

2. Customer details form based on Experiment 2
