Experiment 10

Implement sessions and cookies to store information across multiple pages based on Experiment 02.

Files Included

index.php stores session data like visit history and store information.

products.php displays products and remembers page visits using session.

details.php stores the last viewed product in session.

contact.php stores customer name and email in cookies for reuse.

clear.php clears both session and cookies.

data.php contains product information shared by multiple pages.

How to Run

1. Start a local PHP server from the project root.

cd /Users/rajansmac/Web-tech-projects

php -S localhost:8000

2. Open http://localhost:8000/Experiment_10/index.php

3. Visit the products and contact pages to see session and cookie data persist across pages.

Why this page is HTML

This page explains the experiment and works on static hosting. The session and cookie features run through the PHP pages on a local or PHP-enabled server.
